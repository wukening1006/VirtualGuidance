# Codex 项目开发规范

## 语言与注释规范

- 所有新建脚本必须使用简洁的中文注释。
- 类、public 字段、public 方法需要说明用途。
- Inspector 中需要手动配置的字段，需要说明用途。
- 关键逻辑需要添加中文注释，例如：主任务流程、展品检查、Anchor 配置、Reset 触发、碰撞预测、状态切换、数据记录。
- 不要给简单代码添加无意义注释，例如普通赋值、简单 return、简单循环。

## Inspector 配置要求

- 需要人工配置的字段，尽量使用 [Header] 或 [Tooltip] 简单说明。
- 涉及距离、时间、角度的字段，需要写清楚单位。
